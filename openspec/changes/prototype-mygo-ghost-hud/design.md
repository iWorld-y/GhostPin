# Design

## Context

macOS 版由 `WindowCoordinator` 管理 AppKit 面板，用 SwiftUI hover 事件驱动穿透隐身。交互模式显式获取键盘焦点，切回时显式交还。置顶和跨 Space 是独立开关。Windows 版在 `windows-native/` 维护独立的 Rust/Win32 实现。原型的比较基准来自 `ghost-hud` 和 `hud-doing-focus-and-hover-ghost`。

mygo 已有菜单栏样例和后台面板的 hover 测试。该测试覆盖面板可见且应用在后台时的指针移动。穿透开启且窗口透明度为零的组合需要另行验证。mygo 的普通窗口与 `Panel` 在焦点和 Space 行为上也有不同的实现。

## Goals / Non-Goals

- 使用 mygo 的公开 API 验证幽灵 HUD 的窗口行为，保留可在真实桌面上复测的入口。
- 用最小列表确认原生 UI 绘制、按钮和键盘输入与窗口模式联动。
- 兼容现有任务、偏好与发行身份属于正式迁移阶段。原型依靠独立应用身份和内存状态验证窗口能力。

## Decisions

### 独立 Go 工程

在 `experiments/mygo-hud/` 增加 Go 模块、原生 `ui.View`、内存任务夹具和启动说明。应用层只使用 Go 标准库和 mygo 公开 API。Swift 桥接、直接调用 AppKit 和 WebView 方案均不符合本次验证的技术边界。为可启动的原型使用独立执行文件名和应用身份。菜单栏通过 mygo 的 accessory 模式常驻。

框架起点是本地 mygo checkout 的 `400ba3b17c3ec60ef9b0604e26aa4cdcf2a2ff2d`，其 `go.mod` 要求 Go 1.27.3。实现时固定可复现的模块版本或提交。若该提交只能从本地 checkout 使用，通过启动说明给出临时 `go.work` 配置步骤，避免让提交的模块依赖机器专属绝对路径。记录实际构建版本和任何改用版本的原因。

### 窗口创建和输入模式

先试普通无边框、透明、禁止自身全屏的窗口。创建时启用 `IgnoreMouseEvents` 并保持隐藏，应用完成托盘、置顶和跨 Space 配置后用 `ShowInactive()` 显示。先选普通窗口是因为 mygo 在这条路径上有针对 `SetVisibleOnAllWorkspaces` 开关全屏辅助标记的测试。对照验证 `Panel`，它允许取得键盘焦点且保持应用不激活，但创建时已把全屏辅助标记打开，关闭跨工作区时不会走普通窗口的标记还原分支。

模式切换、显示和窗口属性在 mygo 主线程上更新。切入交互后恢复交互透明度并明确获取焦点。切回时先恢复穿透，再验证公开焦点接口能否交还键盘输入并保持 HUD 可见。macOS 上 `Blur()` 实际调用 `orderBack:`，需要观察键盘输入和窗口层级。必要时对照同一窗口的 `Hide()` 与 `ShowInactive()` 组合，记录闪烁或层级变化。通过全部场景后再确定窗口选项。普通窗口和 `Panel` 使用同一份验收步骤。

### 穿透隐身与双屏操作

隐身状态由当前模式、HUD 可见性与指针是否在窗口范围内推导。优先验证 mygo 的公开指针事件。若事件在穿透或透明度归零后中断，使用 `Screen.CursorScreenPoint()` 和 `Window.Bounds()` 判断范围。只在穿透且窗口显示时采样，进出、移动、缩放及模式切换时重新求值，仅在目标透明度变化时更新窗口。在副屏和含负坐标的布局下验证同一套命中判断。

列表用内置的 Todo 和 Doing 两个状态验证推进。只在交互模式接收按钮输入，保留明确的焦点提示，完成后从当前列表移除。拖动用 mygo 原生 UI 的窗口拖动区域，缩放优先用 mygo 的窗口尺寸能力。模式变化时沿用同一窗口的位置和尺寸。

## Risks / Trade-offs

- 穿透与全透明可能使窗口收不到指针事件。指针坐标采样可以验证行为，需限制在窗口显示且处于穿透的时段。
- 键盘焦点、普通窗口层级和全屏 Space 由系统共同决定。若公开 API 无法满足某个场景，记录最小复现、涉及的 API 和需要补齐的 mygo 能力，作为采用框架的判断依据。
- 无桌面构建只能验证工具链和 Go 代码。用 macOS 14 与可用的较新版本记录可见性、键鼠输入及双屏操作，明确记录缺失的测试条件。

## Migration Plan

在实验分支从独立命令启动原型，验收结束后从自身菜单退出。正式重写按后续变更推进。进入正式迁移时，应继续满足已发布的任务数据、CLI、Skill 与 macOS 应用身份契约。
