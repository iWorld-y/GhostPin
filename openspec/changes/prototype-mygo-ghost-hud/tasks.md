## 2. 穿透、焦点与窗口操作

- [ ] 2.1 接入两种输入模式和置顶切换。在原应用的编辑区域前显示 HUD，观察默认点击穿透、编辑器免点击继续输入、取消置顶后可被覆盖和重新置顶。
- [ ] 2.2 实现指针进入时透明度归零、移出时恢复，必要时使用 mygo 屏幕坐标采样。用 Go 检查覆盖模式与透明度推导，在 macOS 桌面验证连续往返、显示时指针已在范围内、切回穿透时指针已在范围内，以及全透明时点击仍能穿透。

- [ ] 2.4 验证普通无边框窗口与 `Panel` 的焦点及跨 Space 行为，选择满足规格的配置。用另一桌面 Space 和系统全屏应用分别验证开、关、再开。将没有公开 API 可实现的行为连同最小复现写入验收记录。
