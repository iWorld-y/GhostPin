# Spec Delta

## ADDED Requirements

### Requirement: macOS HUD 的交互视图与收展

macOS HUD SHALL 在交互模式提供列表和四象限选择。穿透模式 MUST 使用紧凑列表。通过菜单栏或已配置的模式快捷键切换时，HUD SHALL 按同一规则收展，并保留原有穿透及指针隐身行为。

#### Scenario: 从四象限往返

- **WHEN** 用户在交互模式选择四象限，切回穿透模式
- **THEN** HUD 收为列表，窗口恢复列表尺寸并贴到当前显示器可用区的最近一边，点击穿透至下方应用
- **WHEN** 用户再次进入交互模式
- **THEN** HUD 展开为四象限窗口，尽量还原收起前的四象限 frame

#### Scenario: 从列表往返

- **WHEN** 用户在交互模式选择列表，切回穿透模式后再进入交互模式
- **THEN** HUD 始终显示列表

#### Scenario: 指针离开

- **WHEN** 用户保持交互模式并将指针移出四象限窗口
- **THEN** 四象限保持展开

### Requirement: 交互四象限收起自动贴边

仅交互四象限→穿透列表这一转换 SHALL 把收起后的列表贴到当前显示器 visibleFrame 的最近一边。边缘选择 MUST 以收起前窗口四条边到可用区对应边的间距判断（已碰边算零），平局 MUST 确定性选择并优先左右边。贴边后所选轴 MUST 贴齐可用区边缘，另一轴 SHALL 尽量保持原位置并夹取，且 MUST 保持列表可见与已选尺寸。手动列表/四象限互切与交互列表/穿透列表往返 MUST NOT 吸边。收起后再次进入交互恢复四象限时 SHALL 尽量还原收起前的四象限 frame，显示器变化时作必要夹取；穿透态重启 SHALL 恢复合理的列表位置。

#### Scenario: 按最近边收起

- **WHEN** 交互四象限窗口靠近当前屏可用区某一边，用户切回穿透模式
- **THEN** 列表贴到该边，另一轴尽量保持原位置并夹取，尺寸保持列表已选尺寸

#### Scenario: 平局与多屏

- **WHEN** 收起前窗口到多条边的间距相等，或窗口位于含负坐标的外接显示器
- **THEN** 平局按确定顺序优先左右边选择，并贴到窗口所在显示器的可用区边缘

#### Scenario: 手动切换不吸边

- **WHEN** 用户在交互模式手动于列表与四象限之间切换，或在交互列表与穿透列表之间往返
- **THEN** 窗口沿用固定左上角规则，不自动贴边

#### Scenario: 恢复四象限与穿透重启

- **WHEN** 用户收起后再次进入交互模式，或在穿透态重启应用
- **THEN** 交互模式尽量还原收起前的四象限 frame（显示器变化时夹取），穿透态恢复收起后的列表位置
